👋 Welcome! Follow these steps to run the system on your PC:

┌─────────────────────────────────────────────────────────────┐
│ STEP 1: Download Model File (REQUIRED)                     │
└─────────────────────────────────────────────────────────────┘

   1. Go to: https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF
   2. Download: tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf (637 MB)
   3. Rename to: tinyllama.gguf
   4. Place in: models/tinyllama.gguf

┌─────────────────────────────────────────────────────────────┐
│ STEP 2: Run Setup Script (EASY)                            │
└─────────────────────────────────────────────────────────────┘

   macOS/Linux:
   $ cd RAG_Sanskrit_Saurabh
   $ ./setup.sh

   Windows:
   > cd RAG_Sanskrit_Saurabh
   > setup.bat

   This will:
   ✓ Create virtual environment
   ✓ Install all dependencies
   ✓ Run tests

┌─────────────────────────────────────────────────────────────┐
│ STEP 3: Start Using!                                       │
└─────────────────────────────────────────────────────────────┘

   Option A - Web Interface (Recommended):
   $ streamlit run app.py
   Then open: http://localhost:8501

   Option B - Command Line:
   $ python code/main.py --test
